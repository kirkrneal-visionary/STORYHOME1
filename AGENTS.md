# Agent notes (Story Home)

## How to talk to the human operator

Keep ops asks **dead simple**. Do not make them dig through repo files.

### When SQL must run in Supabase
1. Give the **direct SQL editor link**
2. Paste the **full SQL in the chat** (ready to copy)
3. Say: open link → paste → Run → reply **DONE**
4. **You** run any `npm` / audit / verify steps after they say DONE — do not ask them to run npm

### Style
- Short. Plain English. No jargon stacks.
- One thing to do at a time when possible.
- Prefer “paste this” over “apply migration 0031 from the repo.”
