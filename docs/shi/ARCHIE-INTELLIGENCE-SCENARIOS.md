# ARCHIE-INTELLIGENCE-SCENARIOS

## Promise
Research property scenario board on CAD evidence — rungs 8–10 only. Your assumptions in; labeled ranges out. Never a sale forecast, AVM, or seller probability.

## Ships
- `runIntelligenceScenario` — CAD value stress (low/mid/high) + rate/down/term carry cases
- Kill switch when parcel has no CAD market value
- Coverage label from tax-year count + lookalike valued N (strong / moderate / thin / unavailable)
- UI board on Research CAD evidence panel + meeting-pack print
- Armor: `npm run test:intelligence-scenarios` (via `test:shi`)

## Honesty
- CAD market value = county appraisal observation, not list/sale price
- Ranges illustrate financing math under **your** stress % and loan knobs
- Coverage describes **data support**, not P(sell) or “accuracy %”

## Out of scope
- Seller probability / days-to-list odds  
- AVM “true value”  
- Mutating CAD  
- Corridors traffic growth scenarios (already live separately)
